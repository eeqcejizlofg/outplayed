## Overview

Outplayed is an Overwolf-powered automatic clip recorder that uses game event triggers to automatically save highlights — kills, victories, assists, ace rounds, and more — without requiring a manual hotkey press. Covering over 700 PC games, it stores clips locally and optionally uploads to the Outplayed platform for sharing.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Outplayed** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Auto-Capture** | Game event triggers automatically clip highlights without button presses |
| **700+ Games** | Automatic event detection across more than 700 supported PC titles |
| **Highlight Detection** | Kills, aces, victories, and custom events trigger automatic saves |
| **Local and Cloud** | Store clips locally or sync to Outplayed cloud for cross-device access |
